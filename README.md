# ISW / CTP ROCA — complete reports with images: July–December 2024

Complete copies of the daily *Russian Offensive Campaign Assessment* (Institute for the Study of War / AEI Critical
Threats Project) for **July–December 2024**: full text plus every map and chart in the report. Used with ISW/CTP's permission for
analysis; the reports remain © ISW/CTP.

Open any `data/<year>/<YYYY-MM-DD>/report.md` on github.com to read the report with its maps inline.

```
data/index.csv                         reports in this repo (date, url, title, authors, words, images, ...)
data/<year>/<YYYY-MM-DD>/report.md     full report text; images referenced as images/<file>
data/<year>/<YYYY-MM-DD>/images/       maps and charts at the resolution ISW/CTP published them
data/<year>/<YYYY-MM-DD>/body.html.gz  original article-body HTML
```

The text-only corpus for all periods, the crawler and the index of which repo holds which period are in
[ISW_ROCA_text](https://github.com/bspark1982-source/ISW_ROCA_text).
